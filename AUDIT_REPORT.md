# TaskFlow — итоговый отчёт проверки

Дата проверки: 26 августа 2026 года.

## Результат

Проект покрывает обязательный MVP и полный уровень задания. Из бонусов реализованы фильтры, поиск, локальный лог активности, тёмная тема и горячие клавиши. Не реализованы только вложения файлов непосредственно к задачам; Supabase Storage используется для аватаров.

- Production: <https://taskflow-one-livid-94.vercel.app>
- GitHub: <https://github.com/FreeTeme/taskflow>
- Supabase project: `taskflow`
- Remote migrations: `001–005`, полностью синхронизированы
- Remote database lint: ошибок нет

## Автоматические проверки

- `npm test`: 3 файла, 6 тестов — успешно.
- `npm run build`: успешно; TypeScript и Vite без ошибок.
- `npm run lint`: код возврата 0; ошибок нет, 7 рекомендательных React-предупреждений.
- `npm run test:local`: 30 интеграционных проверок — успешно.
- `supabase db reset`: миграции `001–005` применяются с чистого состояния.
- `supabase db lint --level warning`: ошибок схемы нет локально и удалённо.

Интеграционный сценарий покрывает Auth, default columns, owner/member RLS, запреты outsider, CRUD колонок/задач, детали и дедлайн, комментарии, Realtime, Storage, профиль, атомарный reorder, запрет cross-board move, снятие assignee при удалении участника и cascade-удаление доски.

## UI-проверка

Локально через браузер проверены создание/редактирование/перемещение задач, комментарии, поиск и фильтры, приглашение и удаление участника, owner/member controls, профиль и аватар, тема, keyboard/focus поведение модалок и мобильные размеры полей.

В production проверены:

- загрузка и redirect на `/login`;
- прямое открытие и reload `/register` через SPA rewrite;
- отсутствие browser console errors/warnings;
- соединение с удалённым Supabase Auth;
- корректное пользовательское сообщение при неверных данных входа.
